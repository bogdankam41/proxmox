🛡️ Proxmox AdGuard Home (IaC)
Автоматизированное развертывание и настройка AdGuard Home в LXC-контейнере на Proxmox с использованием Terraform.

🚀 Основные возможности
Полная автоматизация: От создания контейнера до готового DNS-сервера.

Smart DNS Setup: Автоматическое решение конфликта с systemd-resolved (освобождение порта 53).

Конфигурация как код: Настройки AdGuard (фильтры, клиенты, апстримы) хранятся в шаблоне AdGuardHome.yaml.tpl.

Безопасность: Пароли и ключи вынесены в переменные и не попадают в Git.

📁 Структура проекта
main.tf — Описание ресурсов Proxmox и логика установки.

variables.tf — Описание входных переменных.

AdGuardHome.yaml.tpl — Шаблон конфига AdGuard с поддержкой переменных.

terraform.tfvars — (Игнорируется Git) Ваши реальные секреты.

🛠️ Быстрый старт
1. Подготовка
Убедитесь, что у вас есть API-токен Proxmox и настроен SSH-доступ.

2. Настройка переменных
Создайте файл terraform.tfvars на основе ваших данных:

Terraform
ssh_key_path          = "~/.ssh/id_ed25519"
adguard_password_hash = "ваш_bcrypt_hash_пароля"
# Другие переменные провайдера Proxmox...
3. Развертывание
Bash
terraform init
terraform apply
🌐 Доступ к панели
После завершения установки AdGuard будет доступен по адресу:
http://<IP_КОНТЕЙНЕРА>:80 (настроен в конфиге).

⚠️ Важное замечание
Файл terraform.tfvars содержит чувствительные данные. Никогда не фиксируйте его в Git! Он уже добавлен в .gitignore.
